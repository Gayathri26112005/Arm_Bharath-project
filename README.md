# Gesture Media Control

A real-time hand gesture–based media controller using OpenCV, MediaPipe, and PyAutoGUI.

## Setup
pip install opencv-python mediapipe pyautogui

## Run
python gesture_media_control.py

## Gestures
0 → Pause  
1 → Play  
2 → Volume Up  
3 → Volume Down  
4 → Forward  
5 → Backward
